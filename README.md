# SP-8 RPM 計算機

スピードメータテスタ校正器 **SP-8**（滝本計器製作所）専用のRPM計算アプリです。  
iPhoneのホーム画面に追加してアプリとして使えます。

---

## 📱 iPhoneでの使い方

1. SafariでこのアプリのURLを開く
2. 画面下の共有ボタン（□↑）をタップ
3.「ホーム画面に追加」→「追加」をタップ
4. ホーム画面にアイコンが追加されます

---

## 機能

### 通常計算タブ
ローラ径と校正したい速度を入力すると、必要なRPMを自動計算します。

1. ローラ径をボタンで選択、または直接入力
2. 校正速度をボタンで選択、または直接入力
3. 必要なRPMが自動表示されます

**結果の見方**
- 🟢 緑：SP-8の測定範囲内（300〜2,200 rpm）
- 🔴 赤：SP-8の測定範囲外

### ローラ径補正タブ
実際のローラ径がSP-8の設定径と異なる場合に、実際の車速を求めます。

**使う場面**  
スピードメータテスタのローラは摩耗や製造誤差により、公称値（185φなど）と実際の径がズレていることがあります。たとえば実測190.7φのローラをSP-8の185φ設定で使用すると、ストロボが40km/hで同期しても実際の車速は約41.3km/hになります。このズレを正確に把握するために使用します。

**手順**
1. SP-8のボタンで選択しているローラ径を入力
2. 実際に計測したローラ径を入力
3. ストロボが同期した時のSP-8の表示速度を入力
4. 実際の車速と誤差が表示されます

---

## 対応ローラ径

| ボタン | ローラ径 |
|--------|----------|
| 148φ | 148 mm |
| 163φ | 163 mm |
| 185φ | 185 mm |
| 190.7φ | 190.7 mm |
| 370φ | 370 mm |

※ ボタン以外の径は直接入力できます

---

## SP-8 仕様

| 項目 | 仕様 |
|------|------|
| 測定範囲（回転数） | 300〜2,200 rpm |
| 測定範囲（速度） | 12.0〜80.0 km/h |
| 基準速度 | 40.0 km/h / 60.0 km/h |
| 電源 | AC85V〜264V |
| メーカー | 有限会社 滝本計器製作所 |

---

## 注意事項

- 185φ・190.7φのローラで80km/h以上を測定する場合、2,200rpmを超えるためSP-8の測定範囲外となります
- 本アプリの計算結果はあくまで参考値です。実際の校正作業は取扱説明書に従って行ってください
- π（円周率）は取扱説明書に準じて **3.1415** を使用しています
